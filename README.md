# Inventory Management - Phase 1

This repository contains the Phase 1 skeleton for the Enterprise Multi-Branch Inventory & ERP system.

Quick start:

1. Copy `.env.example` to `.env` and update values.
2. Install dependencies:

```bash
npm install
```

3. Run development server:

```bash
npm run dev
```

The app listens on `PORT` from the environment (default 3000).
